# Manifest of the depot images: single source of truth for CI and local tests.
#
# Columns (separated by "|", blank lines and # lines are ignored):
#   id | build context | Dockerfile | published image | platforms | test profile | expected | build args | depends on | max size (MB)
#
#   - platforms: comma-separated list (linux/amd64,linux/arm64)
#   - test profile: file tests/profiles/<profile>.sh
#   - expected: value passed to the profile (major version, python version, ...)
#   - build args: comma-separated KEY=VALUE; {id} is replaced by the base image of that id
#   - depends on: id of another manifest image that is built and tested first
#   - max size: size budget in MB (uncompressed); the test run fails when an image grows past it
#
# An image is only published if ALL its tests pass (see tests/run.sh --publish).
